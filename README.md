# Kayzer Performance

Optimiseur Windows 11 pour joueurs : analyse réelle du PC, réglages documentés, vérifiés et annulables.

- **Site** : https://notecoo.github.io/kayzer/
- **Télécharger la dernière version** : [KayzerPerformance-Setup.exe](https://github.com/NotEcoo/kayzer/releases/latest/download/KayzerPerformance-Setup.exe) (Windows 11 64 bits)
- **Licences** : essai gratuit 24 h, 30 jours ou à vie, sur la boutique.

Ce dépôt public ne contient que le site, les installateurs publiés (onglet *Releases*) et le manifeste de mise à jour signé (`updates/`). Le code source du logiciel n'y figure pas.

Chaque installateur est accompagné de son empreinte SHA-256 dans les notes de version. Le logiciel ne s'installe et ne se met à jour qu'à partir d'un manifeste signé par l'éditeur.
